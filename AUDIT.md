# Аудит сайта «Воин Света» — 11.09.2026

Вторая итерация: аудит проведён с учётом новой вводной (акция на абонементы,
состав полей формы, чат-бот-администратор, деплой на GitHub Pages).
Формат: **найдено → сделано**.

---

## 1. Цены и конверсия (главное)

| Найдено | Сделано |
|---|---|
| В FAQ была устаревшая цена «от 4500 ₽» без выделения | Новая секция **«Цены»** (`#pricing`, есть в меню): карточка «Пробная — 0 ₽» + карточка акции |
| Акция нигде не показывалась | Акция оформлена продающе: обычная цена **от 4 900 ₽/мес — зачёркнута**, временная **от 3 900 ₽/мес** крупно золотом, бейдж «Акция набора», дедлайн-мотивация «идёт набор, мест ограничено», CTA «Записаться по акции» и «Подробности по телефону» |
| Срочности не было нигде кроме текста | Акция продублирована в hero (подстрока под CTA с зачёркнутой ценой), в FAQ и в JSON-LD (тексты синхронизированы через константу `PRICE_FAQ_ANSWER`) |
| Порядок секций не подводил к цене | Секция цен вставлена сразу после «Пути ученика» — родитель сначала видит ценность и путь роста, потом цену |

## 2. Форма заявки

| Найдено | Сделано |
|---|---|
| Три обязательных поля (имя, телефон, возраст) — лишнее трение | **Телефон — единственное обязательное поле**; имя и email — по желанию (с проверкой формата email, если заполнен); возраст убран из обязательных (переехал в комментарий-подсказку) |
| Нет упоминания, кто перезвонит | В успешном состоянии: «на звонки отвечает тренер Александр» + телефон |

## 3. Чат-бот «администратор» (без API)

- Новый компонент `ChatBot.tsx`: плавающая кнопка с индикатором «онлайн», панель
  чата с типографикой мессенджера, индикатором «печатает», авто-прокруткой,
  закрытием по Escape, `aria-live` для сообщений.
- База знаний — `CHAT_RULES` в `content.ts` (править тексты можно без знания кода):
  цены/акция, запись, расписание, адреса, возраст, девочкам, спарринги/безопасность,
  сборы «Зарница», тренеры, ступени, приветствие, благодарность + fallback.
- Бот выполняет главную задачу: **предлагает оставить заявку** (кнопка скроллит
  к форме и сворачивает чат) **и/или связаться напрямую с тренером**
  (кнопка-чип «Позвонить тренеру» → `tel:`). В ответах подчёркнуто: на звонки
  отвечает тренер Александр.
- Подпись в чате честная: «онлайн · отвечает сразу» + приписка «бот отвечает на
  основные вопросы».
